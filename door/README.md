# Door subsystem

This folder contains the complete Door subtask implementation and its development notebooks.

## Production inference

- `inference.py` reproduces Notebook 7's timestamp parsing, one-second-gap segmentation, 19-feature extraction, and classification.
- `door_final_model.joblib` is the fitted StandardScaler + LogisticRegression pipeline.
- `door_final_features.csv` is the ordered feature contract used by that model.
- `predict.py` provides the command-line entry point.
- `app.py` renders the Door workflow inside the shared Streamlit app.

Run inference from the repository root:

```bash
python -m door.predict \
  --input PS3/02_Datasets/Door/Test.csv \
  --output outputs/door/door_predictions.csv
```

Run the integrated app:

```bash
streamlit run app/main.py
```

## Training and analysis

The numbered notebooks document the original workflow from EDA and segmentation through feature engineering, model validation, final training, and inference. Run them in numeric order with `door/` as the working directory; their dataset paths point to `../PS3/02_Datasets/Door/`. Intermediate feature CSVs are generated by the earlier notebooks.

`06_finalModel.ipynb` trains and writes the production model and feature list. `07_inference.ipynb` is retained as the source analysis; production inference is implemented in `inference.py` and regression-tested against its saved `door_predictions.csv`.
